# v0.1.0 → v0.1.1 变更日志

> 发布日期：2026-07-27

## 概览

本次发布包含两项重大改进：TypeScript strict mode 全量合规，以及 TUI 全帧重绘 + 3 段式 IDE 布局重构。

## 1. TypeScript strict mode 合规

### 背景

项目升级 TypeScript `strict` 模式后，8 个 workspace 中出现多类严格检查错误，阻塞 CI 阶段 2。

### 修复内容

| 包 | 问题 | 修复 |
|---|---|---|
| `@vynth/core` | `error-codes.ts` 索引签名与默认码映射 | 新增 `VC-xx0099` 默认码；`DEFAULT_CODE_BY_FAMILY`  broaden 为 `Record<string, VynthErrorCode \| undefined>` |
| `@vynth/mcp` | `mcp-client.ts` stdout 空值访问 | 添加 `proc.stdout != null` 守卫 |
| `@vynth/sandbox` | `harden.ts` Pick 类型缺失 `command` | `Pick<HardenSpec>` 显式包含 `command` |
| `@vynth/sandbox` | `sandbox.ts` stdout/stderr 空值 | `formatErr()` 添加 null guard |

### 工程改进

- `package.json` 新增 `@types/node` + `@types/bun`
- `tsconfig.base.json` 配置 `types: ["node", "bun"]`，移除 DOM lib
- CI 阶段 2 增加 8 个 workspace 的 `bun x tsc --noEmit` 检查

### 验证

```bash
bun x tsc --noEmit  # 8 workspace 全绿
```

## 2. TUI 全帧重绘 + 3 段式 IDE 布局

### 背景

之前的 TUI 使用 DECSTBM（DEC Set Top and Bottom Margins）实现滚动区域 + 增量绘制，导致：
- SGR 颜色泄漏到滚动区域外
- `eraseDown` 溢出到底部固定区域
- 中 CJK 字符宽度计算不准确导致对齐错位

### 解决方案

**废弃 DECSTBM**，改用全帧重绘策略：

```
┌──────────────────────────────────────┐
│ 状态栏（固定顶部）                    │
├──────────────────────────────────────┤
│                                      │
│ 聊天区域（全帧重绘，scrollback 2000） │
│                                      │
├──────────────────────────────────────┤
│ ╭─ 输入框（4 行矩形） ─╮             │
│ │                      │             │
│ ╰──────────────────────╯             │
└──────────────────────────────────────┘
```

### 核心改进

1. **全帧重绘循环**：每次渲染发送 `ESC[2J` 清屏 + 逐行写满 + 每行 `\x1b[0m` 收尾，彻底消除颜色泄漏
2. **3 段式布局**：顶部状态栏、中部聊天区、底部输入框，各段独立管理
3. **角色标签移除**：不再显示 `▎System` / `▎Vynth` / `▎You` / `▎Tool`，改用左侧颜色条区分
4. **矩形输入框**：4 行高度，`╭─╮` / `│` / `╰─╯` 边框，支持多行输入
5. **CJK 感知宽度**：`visibleWidth()` 正确处理中文/日文/韩文（2 列/字符）
6. **Scrollback 缓冲区**：2000 行环形缓冲区，支持历史导航
7. **鼠标滚轮支持**：SGR 1006 协议解析，滚轮事件映射 scrollback 偏移

## 4. 迁移指南

### 从 v0.1.0 升级

```bash
git pull origin main
bun install
bun run compile
```

### 破坏性变更

**无**。本次发布为 patch 版本，不包含 breaking changes。

### 已知限制

- 全帧重绘在极低带宽终端（如 9600 波特）下可能闪烁，正常 SSH/本地终端无此问题
- 鼠标滚轮仅支持 SGR 1006 协议（xterm / iTerm2 / Windows Terminal / VS Code 终端均支持）
