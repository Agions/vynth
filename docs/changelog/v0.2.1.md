# Vynth v0.2.1 发布说明

> 本次发布 · 版本 `0.2.1` · 单二进制 `dist/vynth`（实测 60.51 MiB）
> 完整变更日志见根目录 `CHANGELOG.md`。

## 一句话定位

**v0.2.1 是「错误码 6 位体系落地 + demo 模式下线 + 默认模型回滚」的 patch 发布**。
所有改动向后兼容（错误码由 `fromLegacy()` 桥接，版本号 0.2.0→0.2.1 不破坏数据格式）。

## 本次变更

### ✅ 错误码 6 位码（VC-XXXXXX）落地

- 新增 `packages/core/src/error-codes.ts`：权威错误码表，22 个已声明码 +
  6 个族默认回退码（VC-XX0099），`isVynthErrorCode()` / `fromLegacy()` / `describe()`
  三个工具函数 + 8 个单测。
- `packages/core/src/errors.ts`：`VynthError` 基类新增 `numericCode: VynthErrorCode`
  权威字段；`code: string` 旧字段保留向后兼容；子类构造函数第二个参数可显式
  传 6 位码。
- `packages/sandbox/src/sandbox.ts`：网络阻断 / 超时 / 非 0 exit 三类错误统一带
  `[VC-030003]` / `[VC-030004]` / `[VC-030005]` 前缀；`formatErr()` 自动提取
  `numericCode` 加前缀。
- `apps/cli/src/main.ts`：CLI 参数解析错误前缀 `[VC-010004]` / `[VC-010002]` /
  `[VC-010003]`，便于日志聚合按码告警。
- `packages/harness/src/e2e.test.ts`：CLI 退出码契约新增 6 位码正则断言。
- `docs/development/dev-guide.md`：错误码权威表 + 抛出约定 + 日志格式。

**已声明 6 位码**：
- Config 族（VC-01）：MISSING_KEY / INVALID_MODE / UNKNOWN_FLAG / VALUE_MISSING
- LLM 族（VC-02）：AUTH_FAILED / RATE_LIMITED / NETWORK / INVALID_RESPONSE / PLAINTEXT_HTTP
- Sandbox 族（VC-03）：PATH_ESCAPE / SYMLINK_ESCAPE / NETWORK_BLOCKED / READ_FAILED / WRITE_FAILED
- Tool 族（VC-04）：NOT_FOUND / EXECUTION_FAILED / INVALID_ARGS
- Plugin 族（VC-05）：LOAD_FAILED / MISSING_ACTIVATE / MISSING_NAME
- MCP 族（VC-06）：NOT_IMPLEMENTED / PROTOCOL_PARSE / REQUEST_TIMEOUT

> **迁移指引**：旧字符串 `code` 仍可读；新代码优先用 `numericCode` 做断言与告警。

### ✅ Demo 模式下线（**Breaking**）

- `packages/engine/src/llm.ts`：`createProvider()` 在 `apiKey` 为空时**抛 `LlmError`**
  （不再静默 fallback 到 `EchoProvider`）。
- 移除 `EchoProvider` 类；`packages/engine/src/engine.test.ts` 与
  `packages/harness/src/e2e.test.ts` 的 demo 用例改写为「空 apiKey 抛 LlmError」
  断言。
- `scripts/bench-cold-start.ts`：注入 fake key 走真实 CLI 首字节路径，不再依赖
  demo。
- `docs/guide/getting-started.md` / `docs/guide/configuration.md` / `docs/faq/index.md`：
  「API_KEY 为必填，未设置抛 `LlmError`」写为默认行为。

> **迁移指引**：所有用户须配置 `VYNTH_API_KEY` 才能运行 Vynth。设置方式见
> `docs/guide/configuration.md` 或 `docs/guide/getting-started.md`。

### ✅ 默认模型回滚 `deepseek-v4-pro`

- `packages/core/src/config.ts`：默认模型 `deepseek-v4-pro`（用户最新声明）。
- `packages/core/src/core.test.ts` / `packages/harness/src/e2e.test.ts`：断言
  同步更新。
- `apps/cli/src/main.ts` `--help` 与 `docs/api/overview.md` / `docs/architecture/packages.md`：
  描述同步。

> **为什么回滚**：v0.2.0 历史提交曾将默认改为 `deepseek-chat`，与用户冻结裁决
> `X1/X2`（`deepseek-v4-pro`）冲突，本 patch 修正。

## 快速开始

```bash
bun install
bun run compile                                # → dist/vynth (≈ 60 MiB)

export VYNTH_API_KEY="sk-..."                  # 必填
export VYNTH_MODEL="deepseek-v4-pro"           # 默认，可改
export VYNTH_LLM_BASE_URL="https://api.deepseek.com/v1"

# 无头
./dist/vynth -g '给 src/core 写一份错误码单测'

# 交互 TUI（需真实 TTY）
./dist/vynth
```
