## 为什么选择 Synerix？

AI 编码助手很强大，但**工作流摩擦**会打断你的节奏：

| 问题 | Synerix 的解决方案 |
|------|-------------------|
| 每小时在编辑器、浏览器和终端之间切换 50 次 | **一个终端** - 输入、生成、审查、运行、修复 - 全部在一个地方 |
| 每个文件写入、每个命令、每个按键都需要审批 | **智能沙箱** - Vibe 模式下低风险操作自动审批；危险操作完整预览 |
| 将代码粘贴到聊天中，复制回来，编译，再粘贴错误回来 | **自动迭代** - `描述 → 生成 → 编译 → 测试 → 修复` 在一个循环中完成 |

Synerix 将 AI 编码工作流从 **6 个工具 × 3 个上下文** 压缩到 **1 个终端窗口**。

## 立即开始

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/Agions/synerix/main/install.sh | bash

# Windows (PowerShell 5.1+)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
irm https://raw.githubusercontent.com/Agions/synerix/main/install.ps1 | iex
```

查看 [快速开始指南](/guide/getting-started) 了解更多。
