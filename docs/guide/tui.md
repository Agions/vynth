# TUI 使用指南

`zeno`（无参数）启动全屏交互式终端界面。本页是界面布局、快捷键、斜杠命令与主题的完整参考——与代码同源，以此为准。

## 界面布局（四区）

```
┌──────────────────────────────────────────────────────────┐
│  顶栏  Zeno · 主题 · 状态 · 轮次                          │
├───────────────────────────────────────────┬──────────────┤
│                                           │  侧栏 (^B)   │
│  聊天主区                                 │  文件│任务│  │
│  · 流式回复 / 工具调用块                  │      工具    │
│  · 工具状态: ⠋ running → ✔ ok / ✖ error   │  (^T 切 tab) │
│                                           │              │
├───────────────────────────────────────────┤              │
│  输出窗格 (^O 分屏)：工具输出流聚合       │              │
├───────────────────────────────────────────┴──────────────┤
│  ❯ 输入区（多行编辑 · / @ 触发浮窗）                     │
│  ⏎ send · ^B 侧栏 · ^T 切换 · ^O split · ↑↓ scroll       │
└──────────────────────────────────────────────────────────┘
```

- **侧栏**：常驻右侧，三个 tab——文件（工作区文件列表）/ 任务（后台任务实时状态）/ 工具（agent 已注册工具 + live 徽标）。终端宽度 **< 84 列自动隐藏**，此时按 `^B`/`^T` 会提示当前列数。
- **输出窗格（分屏）**：所有工具调用的状态与完整输出实时聚合，聊天区折叠了也能在这里看全。中区高度 < 10 行时自动禁用。
- **浮窗面板**：`/` 命令、`@` 文件引用及所有斜杠弹窗（`/config` `/usage` 等）均为无边框无底色浮层，锚定输入区上方，不挤占布局。

## 快捷键总表

### 全局

| 快捷键 | 作用 |
| --- | --- |
| `Tab`（空输入时） | 切换 Vibe / Plan 模式 |
| `F1` / `Ctrl+Space` | 命令面板 |
| `Ctrl+U` | Token 用量面板 |
| `Esc` | 关闭当前浮窗 / 面板 |
| `Ctrl+C` | 退出 |

### 布局

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+B` | 开 / 关右侧栏 |
| `Ctrl+T` | 侧栏 tab 循环切换（文件 → 任务 → 工具） |
| `Ctrl+O` | 开 / 关分屏输出窗格 |
| `Ctrl+E` | 分屏焦点在聊天区 / 输出窗格间切换 |

### 滚动与历史

| 快捷键 | 作用 |
| --- | --- |
| `↑` / `↓` | 滚动聊天区（±3 行），**永不触碰输入框** |
| `PageUp` / `PageDown` | 翻页滚动（焦点在输出窗格时滚输出流） |
| `Shift+↑` / `Shift+↓` | 快速滚动 |
| `End` | 回到底部 |
| `Ctrl+P` / `Ctrl+N` | 输入历史 上一条 / 下一条（唯一会改写输入框的方式） |

> 设计约定：鼠标滚轮和方向键只滚屏。部分终端把滚轮上报为方向键，因此历史导航独立到 `^P`/`^N`（readline 约定），保证打字打一半滚屏不丢内容。

### 输入区

| 快捷键 | 作用 |
| --- | --- |
| `⏎` | 发送 |
| `⇧⏎` | 换行（多行输入） |
| `/` | 斜杠命令浮窗（前缀过滤，`↑↓` 选择 `⏎` 确认） |
| `@` | 文件引用浮窗（模糊过滤工作区文件） |

## 斜杠命令

### 配置

| 命令 | 作用 |
| --- | --- |
| `/config` | 可视化配置 AI 模型、端点与 API 密钥 |
| `/model <name> [url] [key]` | 一站式配置模型、Base URL 与 Key |
| `/theme` | 循环切换界面主题 |

> 旧命令 `/api` `/url` `/key` 已归并至 `/model`。误输会得到等价 `/model` 写法提示，不会静默失败。

### 工作流

| 命令 | 作用 |
| --- | --- |
| `/init` | 初始化项目的 `AGENTS.md` AI 规则文件 |
| `/files` | 工作区文件树抽屉 |
| `/search` | 全局内容与代码正则搜索 |
| `/compact` | 压缩上下文历史（Context Compaction） |
| `/undo` | 回撤 / 恢复上一步 AI 代码修改 |

### 系统与统计

| 命令 | 作用 |
| --- | --- |
| `/tokens` | Token 详细消耗与费用面板（同 `Ctrl+U`） |
| `/usage` | Token 用量统计 |
| `/tasks` | 后台异步任务面板 |
| `/lsp` | LSP 语言服务器与诊断状态 |
| `/brief` | 开关折叠工具输出模式 |
| `/clear` | 清空当前对话与上下文 |
| `/help` | 完整帮助手册 |

## 工具调用反馈

聊天区中每个工具调用块带实时状态机：

- `⠋ running` — 执行中（spinner）
- `✔ ok` — 成功
- `✖ error` — 失败，附 `VC-XXXXXX` 错误码脚注与可操作建议（如「检查路径是否越界」）
- 失败的命令不会伪装成成功——transcript 重绘与 live 流两条路径均透传真实状态

## 主题

6 套内置主题，`/theme` 循环切换或 `ZENO_THEME` 环境变量指定：

| 主题 | 风格 |
| --- | --- |
| `mocha`（默认） | Catppuccin 深色 |
| `latte` | Catppuccin 浅色 |
| `midnight` | 极深夜蓝 |
| `forest` | 绿调深色 |
| `light` | 高对比浅色 |
| `neon` | 霓虹高饱和 |

色彩输出自动适配终端能力：支持 truecolor 的终端（iTerm2 / WezTerm / VS Code 等，自动检测 `COLORTERM`）输出 24-bit 色；老终端自动降级到 xterm-256 最近色。

## 终端兼容性建议

- **最低可用**：80 列 × 24 行；**推荐**：≥ 100 列（侧栏 + 分屏全开）
- 需要真实 TTY（raw mode）；管道 / CI 环境用 `zeno -g` 无头模式
- 渲染采用帧级差分：只重写变化的行，长对话滚动不闪屏
