# 使用模式

Synerix 提供多种工作模式，适应不同的编码场景。

## Act 模式

**直接执行，无需离开终端**

Act 模式允许你直接在终端中执行命令，无需切换到其他工具。

### 特点

- 命令行直接执行
- 智能沙箱自动审批低风险操作
- 危险操作完整预览

### 使用场景

- 快速执行构建命令
- 运行测试
- 文件操作

### 示例

```bash
# 在 Synerix 中直接执行
cargo build --release
cargo test
git status
```

## Vibe 模式

**沉浸式编码体验**

Vibe 模式提供 AI 自动迭代的编码体验。

### 工作流程

1. **描述** - 告诉 AI 你想要什么
2. **生成** - AI 自动生成代码
3. **编译** - 自动编译验证
4. **测试** - 运行测试套件
5. **修复** - 自动修复问题

### 特点

- 完整的代码生成循环
- 自动错误修复
- 无需手动干预

### 示例

```
你: 创建一个 HTTP 服务器，提供 /api/users 端点
AI: 正在生成代码...
AI: 编译成功
AI: 运行测试... 通过
AI: 完成！服务器已创建在 src/server.rs
```

## Chat 模式

**与 AI 对话**

Chat 模式提供交互式的 AI 对话体验。

### 功能

- 代码建议
- 代码解释
- 调试帮助
- 文档生成

### 示例

```
你: 解释一下这个 Rust 函数的工作原理
AI: 这个函数使用了所有权系统...
```

## Architect 模式

**架构设计和代码审查**

Architect 模式专注于高层设计和代码质量。

### 功能

- 架构设计建议
- 代码审查
- 重构建议
- 性能优化

### 示例

```
你: 审查这个模块的架构
AI: 建议将数据访问层分离到单独的模块...
```

## Plan 模式

**任务规划和分解**

Plan 模式帮助你将复杂问题分解为可执行的步骤。

### 功能

- 任务分解
- 依赖分析
- 时间估算
- 优先级排序

### 示例

```
你: 规划实现用户认证系统
AI: 建议分为以下步骤：
1. 设计数据模型 (2h)
2. 实现密码哈希 (1h)
3. 创建 JWT 令牌 (2h)
...
```

## 模式切换

在 Synerix 中可以随时切换模式：

| 快捷键 | 模式 |
|--------|------|
| `Ctrl+1` | Act 模式 |
| `Ctrl+2` | Vibe 模式 |
| `Ctrl+3` | Chat 模式 |
| `Ctrl+4` | Architect 模式 |
| `Ctrl+5` | Plan 模式 |
